# wheelbipeV14_2 碰撞体与 ToF

`base_link_collision` 使用 `base_link.STL` 加上可视几何的 `z=-0.117 m` 偏移后，主体（`|y| <= 0.2 m`）的轴对齐包围盒。四个侧面突出部件分别使用独立盒体，避免把主体到侧面部件之间的空隙填成一个全宽箱体。

主体范围约为 x `[-0.252429, 0.267485]`、y `[-0.150001, 0.150001]`、z `[-0.167001, 0.075903]` m。底面与可视网格的 `-0.167 m` 对齐；盒体是包含外形的简化包络，不表示网格的每个凹槽。惯量仍取显式 `inertial` 参数。

默认 ToF 光心与这里的 site 一致：前向 `(0.28, ±0.15, -0.18)` m，下向 `(0.10, ±0.12, -0.18)` m。前向光轴前下 45°，下向光轴沿机身 -Z。配置位于 `src/genesis/wheel_leg_infantry/sensors/tof.py`，`mount_revision=2`。旧存档中精确匹配上一版默认位置的光心会在配置解析时迁移，其他自定义位置按保存值使用。

碰撞体更新会改变接触行为。训练 recovery 和交互复位会按当前碰撞几何向上校正旧快照的高度，保留关节构型；静态复位至少留 0.1 mm 间隙，动态复位保留配置的释放间隙。ToF 入地/贴地时报告最近距离，避免把遮挡当作 no-hit。已有策略可加载，但应在新几何和测距语义下验证并续训。
